## Description

This repository focuses on scraping web applications and mobile apps, capturing network requests (sniffing APIs), and sharing the captured data. Whether you're a developer needing API insights or someone looking to scrape specific websites/apps, this project provides tools and resources to facilitate that.

Anyone can request scraping for their web or app, and we can share the captured APIs and data.

## Features

- Web scraping capabilities
- App API sniffing and capture
- Request logging and analysis
- Shared API endpoints and data
- Custom scraping requests
- Organized data storage

## Project Structure

- `WEB-SCRAPE/`: Contains web scraping scripts and captured data
- `APP-SCRAPE/`: Contains app scraping tools and API captures
- `EXTRA/`: Additional resources and utilities
